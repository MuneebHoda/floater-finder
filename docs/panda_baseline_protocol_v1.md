# PANDA development zero-shot baseline v1

Recorded before any 120-cohort cancer predictions were inspected. The prompt YAML and scoring implementation were already fixed in the submitted immutable snapshots; this document records their behavior.

- **Inputs:** 120 balanced Radboud WSIs, 50,729 RGB-selected representative tiles, CONCH v1 projected and normalized 512-dimensional image/text embeddings. Fixed prompts: `configs/panda_morphology_v1.yaml`. Canonical preprocessing is unchanged. Grading masks neither select clean tiles nor enter this scorer.
- **Splits:** 24 training, 8 calibration and 8 test slides per group (benign ISUP 0, GG1 ISUP 1, high ISUP 4–5). Development scoring loads 72 train + 24 calibration cases. All 24 final-test cases remain unscored. Patient identifiers are unavailable; independence is verified only by slide ID.
- **Primary engineering task:** original slide ISUP 0 versus original slide ISUP 1/4/5. Development class supports are 24 benign / 48 cancer in training and 8 / 16 in calibration. These are slide labels, never tile truth.
- **Exploratory task:** ISUP 1 versus ISUP 4–5; benign slides are excluded. Supports are 24 / 24 in training and 8 / 8 in calibration. This is not a validated Grade Group upgrading model.
- **Scoring:** dot products in the normalized shared image/text space. Compare only the two classes for the specified task. For each class independently, take either all-tile mean, mean of the top `max(1, ceil(0.01*N))`, or top `max(1, ceil(0.05*N))` scores. Select the larger pooled class score; exact ties select the first class (benign / low grade). These cosine scores are not calibrated probabilities. No threshold is tuned for this baseline.
- **Reporting:** retain all three pooling rules, raw per-slide class scores, predictions, class supports, confusion matrices, class recalls, accuracy, balanced accuracy and error IDs, separately for train and calibration. Balanced accuracy exposes the 2:1 cancer/benign class imbalance; an all-cancer predictor has 2/3 accuracy and 1/2 balanced accuracy. Do not present the largest observed pooling score as independent final performance.
- **Data quality:** retain original ISUP labels for the GG1 case whose native mask has no tumor labels and the high-grade calibration case whose annotation fails decoding. The latter's tile fractions remain unknown. Both are eligible for image-only slide scoring; the unusable mask is excluded from annotation/donor tasks. Do not drop or relabel a case based on its prediction.
- **Interpretation:** successful embedding/CPU jobs establish pipeline execution only. Calibration results are descriptive development evidence, not clinical validation. No numerical clinical-validity cutoff is asserted. A degenerate or poorly separating scorer blocks disease-contamination claims. If needed, a simple head on saved CONCH features must be fit using training cases only and assessed on calibration, retaining this baseline unchanged. Keep test scoring behind a separately frozen scorer/protocol.

No donor embedding, contamination experiment, unmodified-slide alert-rate measurement or final-test scoring is performed by this baseline. Prior TCGA organ-classification results remain separate.
