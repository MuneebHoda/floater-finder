# PANDA S1 saved-embedding development stress v1

This follows the executed clean development baseline, which is nondegenerate but not clinically validated. It tests an engineering failure mode rather than estimating final-test effectiveness. All 24 final-test slides stay unscored.

Inputs are the verified 120-slide manifest and embedding receipts from CPU job 23055022. Load image features only for training/calibration. Clean sampling is unchanged and remains RGB-selected. A separate donor view filters saved tile IDs by native GP3+GP4+GP5 annotation fraction **at least 10%**. Unknown/unusable masks supply no donor labels. Spatial components use occupied cells with **four-neighbor adjacency**, no gap bridging. This is connectivity of sampled cancer-rich tiles, not a complete biopsy-piece segmentation. Dedicated donor tiling/embedding can remain necessary for larger fragments.

Each benign host uses a distinct Radboud cancer donor in the same train/calibration split. Hash ordering with seed 20261020 prefers a donor component large enough for the 10% level; otherwise the largest available component is used. Pairing depends on annotation/connectivity/capacity, not classification scores. The same donor and one seeded connected growth ordering are kept across all percentages. Nested prefixes supply **0, 0.5, 1, 2, 5 and 10%**; requested foreign count is `ceil(percent * original_host_tiles / 100)`. No tile duplication, repetition or combining disconnected pieces is allowed. Insufficient capacity is an explicit exclusion, with denominators recorded separately at each level.

No new GPU or downloads occur. The mixture concatenates genuine saved embeddings and translates donor coordinates onto the host's physical grid, three x-grid steps beyond its right edge, with y rounded onto that grid. This intentionally isolated placement is synthetic; no pixel-level foreign tissue or native contamination is claimed. Host and donor must have matching recorded physical geometry. Original saved artifacts are preserved. Known same-patient pairs are refused; unknown patient IDs remain unknown and are disclosed, never replaced by slide IDs.

For every mixture, exact oracle removal must recover original features, coordinates, IDs, metadata and pooled scores. Any oracle failure stops the job. Scoring uses the fixed benign/cancer prompt pair and reports mean/top-1%/top-5% pooling. Top-5% is the development candidate based on the preceding clean baseline, not an independently tested selection. Report clean and contaminated predictions, raw scores, changes, original-host-label accuracy, mixture cancer response, requested/realized counts, donor indices/IDs, footprint area, annotated cancer area and all exclusions. Original-host-label accuracy asks whether the mixture still predicts the original benign host; mixture cancer response asks whether it detects included annotated cancer. These distinct targets must not be conflated.

Only one seed is used. Counts of unique host and donor slides are reported; reused donors and overlapping fragment sizes are correlated observations, not independent patients. No detection, tissue removal, foreignness inference, calibrated alert rate or final-test evaluation is performed by this job. S2/Grade Group upgrading remains exploratory and is not run here.
